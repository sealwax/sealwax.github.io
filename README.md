# Sealwax website

The French and English landing pages for [Sealwax](https://github.com/sealwax/sealwax), published at [sealwax.github.io](https://sealwax.github.io/).

Edit `index.html` and `en/index.html` directly. Both share the stylesheet, script and artwork in `assets/`. Run `python3 -m http.server 8000` in the repository to preview the site. GitHub Pages publishes the root of `main`.

The downloadable `assets/atlas.pdf` is the input for all four examples. Its cover preview was rendered with Sealwax. The site's code and original artwork are MIT licensed. The bundled fonts have their own SIL Open Font Licenses in `assets/fonts/`.
